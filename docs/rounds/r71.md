# R71: `let _? =` の破棄を `do` に書き換える（E504）（r71）
旧 `docs/plan.md` 66 節。実測は `docs/ledger.md`。

## 手順書

### 背景
§35 の `do expression -> continuation` が正準形。`let _? = e ->` は E504 で拒否されるので、1 範囲で `do ` に置き換える。

### 実測した材料
- 正準形: 仕様 §35（`do validate article ->`）、§40（`let _ = calculate ->` は禁止）。受理コーパスに `do …` の実例 6 つ、`let _` / `let _?` は 0。
- 診断の位置は `4:7`（`_` の列）＝ `pat.span`。`let … ->` は `LetQ { pat, value, body }` / `Let { pat, value, body }`。
- **掛からない原因**: walk の腕は `Let` / `LetQ` を 911 / 921 行で既に所有しており、後方に足した腕は dead になる。**所有している腕の中に入れる**のが正解。
- E506（純粋値の破棄）に `do` は使えない（`do x ->` は E303 になる、実測）。だから E504 だけに掛ける。

### 決定
`discard_let_fix` を `LetQ` の腕の中から呼ぶ。範囲は文の開始から値の開始まで、置換は `do `、範囲に `//` があれば掛けない。`is_fixable` に `"E504"`。

### 期待値の根拠
門番が再現から手書きの `do` 版を導き、直した物の実行結果と比べる。ファイル名も件数も判定器に書かない。
