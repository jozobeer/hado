# R75: E505（未使用束縛）の書き換え（2026-09-16）（r75）
旧 `docs/plan.md` 70 節。実測は `docs/ledger.md`。

## 手順書

### 背景
実用 CLI を書く過程で、E515 の正準形どおりに腕を上げると次に E505（未使用束縛）で止まることが分かった。E505 には書き換えが無く、診断にも正準形が無かったため、fix-it が受理に届かなかった。

### 実測した材料
- 再帰の綴りは `def rec 名前 …`（`tests/accept/short_or/main.hd:5`）。
- 引数付きの `def` に腕は書けない（`E100`）。腕を取るのは `def f` の形だけ（§31、E515）。
- 未使用の展開束縛は `...rest` のままだと E505。`_` は検査器が除外する（`check.rs:252`）。
- `check` は入力ルート配下の全 `.hd` を見るので、検体は 1 つずつ別ディレクトリに置く。

### 決定
- E505 を書き換え可能にし、束縛 span を `_` に改名する。判定は検査器と同じ `crate::names::bindings` と `crate::names::references` を使い、検査器と fix-it がずれないようにする（§57、check.rs:257–258 の方針）。
- 1 回の実行で 1 区間という既存の規律は変えない。
