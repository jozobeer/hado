### 決定
標準入力から JSON を読み、コードごとの件数を `CODE n` で出す。組は持たず「まだ印字していないコードか」で 1 回だけ印字する。枝ごとに関数を分ける。

### 期待値の根拠
門番は JSON を python で独立に数え、道具の出力（整列済み）と比べる。ファイル名も件数も判定器に書かない。
